# Misión frontend — Módulo Directivo

Esta versión implementa los cinco módulos exigidos:

1. Dashboard Ejecutivo
2. Dashboard Riesgos
3. Dashboard Obsolescencia
4. Reportes Ejecutivos
5. Roadmap Migración

Dashboard Riesgos es un panel especializado de prevención con KPI, semáforo rojo/amarillo/verde, matriz probabilidad-impacto, riesgos por categoría, cuellos de botella, filtros, tabla, paginación y detalle.

Dashboard Obsolescencia es un panel especializado para equipos, sistemas y licencias caducados o próximos a vencer, con KPI, vigencia, tipos de activo, línea temporal, áreas, renovación técnica/presupuestal, filtros, tabla, paginación y detalle.

El Dashboard Ejecutivo solo resume los demás módulos. El bloque Capacidad de atención por área se expande a todo el ancho para eliminar espacio vacío sin inventar un gráfico redundante.

El sidebar usa los nombres oficiales exactos, Cerrar sesión es un botón visible y se eliminó el reloj de sesión.
