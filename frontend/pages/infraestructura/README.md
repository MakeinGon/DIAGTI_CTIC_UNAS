# Módulo Área de Infraestructura

Pantalla inicial: `html/dashboard.html`

## Menú
- Dashboard
- Mis Sistemas
- Infraestructura
- Historial

## Flujo de estados
Borrador → Enviado → Observado → Corregido → Enviado → Validado

## Registro técnico por pasos
1. Infraestructura
2. Despliegue
3. Seguridad
4. Evidencias

Los botones **Continuar** validan los campos obligatorios del paso actual. Los títulos de los pasos son clicables. En Evidencias, si existen datos incompletos, se permite regresar para completarlos o guardar el avance como borrador.
